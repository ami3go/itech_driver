# Ordered integration audit

This is a disposable Git merge audit, not an integrated release or hardware test. PRs #2–6 plus all primary review PRs #78–148, excluding closed duplicates #135/#137, are attempted in numerical dependency order. The already merged migration #1 is included in the master baseline. The workflow fetches all PR refs before merging, freezes their SHAs and records the base, per-PR result, conflict files, diagnostics and resulting tree SHA. It never pushes. A failed merge is aborted, then the audit continues to identify further conflicts; a later successful merge can include ancestors of a skipped PR, so the report requires semantic interpretation. A clean audit does not establish correctness. Conflicts are intentionally a failing check; download the JSON artifact and resolve shared files semantically on a separate integration branch, then run full offline CI. Never run driver code from an audit merge. No HIL, no deployment, no release. Run manually only in a disposable checkout: python tools/audit_integration.py --base <master-sha> --output integration-audit.json.
