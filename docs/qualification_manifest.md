# Independent qualification manifest

Before physical testing, independently approve and freeze `qualification_manifest.template.json` populated with every required test case, including model, serial, firmware, interface, exact command, guide page, expected result, energized boolean and unique `case_id`. Record full driver/core commit SHA and guide SHA-256, revision and approval reference. Do not derive the manifest from results after the run. Include separate case IDs for repeated/boundary/failure tests of the same command. The evidence report repeats the case fields, supplies actual result, UTC, required=true, result and hashed artifacts. For energized cases, `independent_safe_state_reference` must name an artifact path in the case's hashed artifacts list. All manifest cases must appear exactly once and pass. Run `python -m itech_driver.qualification evidence.json --artifacts evidence_directory --manifest approved_manifest.json` (supersedes earlier CLI examples). Empty template fails. The structural checker cannot authenticate approval, verify that the approved inventory is complete relative to the guide, or certify measurements. Independent technical review remains mandatory. No physical I/O by the checker.
