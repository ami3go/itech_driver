SCPI python wrapper to control Itech power supplies 

Currently supported models:
* IT-M3900D High Power DC Power Supply [https://www.itechate.com/en/product/dc-power-supply/IT-M3900D.html]

## Install

Option 1:
```
pip3 install git+https://github.com/ami3go/itech_driver
```

Option 2:

Clone the repo wherever you want and then

```
pip3 install -e /wherever/you/wanted/to/clone/this/repo
```
  
## Uninstall

To uninstall this package just run

```
pip3 uninstall itech_driver
```
